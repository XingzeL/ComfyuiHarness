## 行为覆盖

- 离线 build 不写入运行记录、不联网、不改变原图模板；随机种子展开并持久保存。
- 换到包含中文与空格的新目录后，复制包可以独立通过 CLI 构建；不依赖原项目或 local 环境配置。
- 标准 LoRA model/CLIP 链路与独立强度，模型 family 不匹配、重复登记、未知参数和数值类型/边界错误。
- 节点重编号后的映射更新，节点类型/字段漂移、重复映射、断链、循环和 UI 图误传。
- 服务不可达、缺失节点、缺失模型、服务端相对名称规范化、连接类型不匹配。
- POST 明确拒绝、5xx 和成功响应缺少任务 ID：记录失败或状态不确定，不自动重投。
- 队列等待、执行中、未知和失败状态；未成功时禁止收集。
- 图像输入快照、上传以及服务返回名称替换。
- 从执行历史收集实际文件名，多输出节点的部分缺失、预期输出为空、图片损坏、疑似纯黑。
- 重复收集保持原文件，文件被改动时拒绝覆盖；历史清理后使用已保存的快照。
- 新 run 关联重试、保留原种子、输出前缀唯一、复现记录完整、路径越界拒绝。
- 未声明的保存节点及特殊保存方式需要适配；CLI 中文 JSON 和错误退出码正确。
- 逐模块模板：Image Save 自定义节点的预检、投递后立即返回、图片尚未存在时记录直接落盘路径、output/jobs 记录、不同提交不覆盖、最近黑图阻止投递、独立复制后 dry-run、拒绝或不确定提交不自动重试。

测试服务器只监听随机回环端口，图片是测试中生成的小型色块，临时文件限定在本包 tmp 中。没有连接真实 ComfyUI，没有下载模型，没有启动、停止或重启服务，没有使用 GPU。
