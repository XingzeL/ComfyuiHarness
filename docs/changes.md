# 维护变更记录

按日期记录会影响后续 Agent 使用方式的维护变化，简要说明改了什么、依据是什么、验证到哪一步。不要求每次任务都升级版本号。

## 2026-10-17

- 增加 INITIALIZE.md，作为复制到新电脑后的初始 Prompt；串联路径确认、版本与启动方式分析、本机配置、脚本实现、资源整理和分层验收，并接入 AGENTS.md 与 README.md。
- 依据：用户要求新 Agent 根据目标电脑环境完成首次安装与补全。验证范围为文档引用和现有入口一致性；未执行本机初始化、安装、服务操作或 GPU 生成。
- 增加 buffer 暂存区及 archive/buffer 归档容器，用于未确定归属、候选路径和待提炼经验。
- 新增维护规则：任务收尾处理本轮缓冲，版本迭代再将有依据的内容提炼到规则、Skill 或模板。
- 依据：用户提出任务多变，需要容纳规则外不确定内容并支持之后版本迭代。本次没有既存缓冲主题需要迁移。
- 验证：检查文档引用及目录；未改运行程序，不涉及生成或服务操作。
