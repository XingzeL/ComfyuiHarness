# 待整理缓冲区

本目录接收文件归属、路径或实现方式尚不明确的内容，以及值得后续提炼的任务经验。维护方法见 [缓冲与迭代规则](../docs/maintenance.md)。

按 `buffer/<任务或主题>/` 暂存，主题内自由组织，不需要为每个文件写一份登记。每个主题留一份简短 README 即可：

```markdown
# 主题

- 暂存内容与当前用途：
- 为什么暂存 / 未确认项：
- 已尝试的方法与结果：
- 下一步 / 可能归宿：
```

已有明确位置的测试、模型资料、任务输出仍放原目录，在这里引用。buffer 不等于 tmp，不批量清空；暂存内容也不自动成为正式规则。

当前没有未决主题。后续主题以子目录为准，任务收尾更新本轮内容，版本迭代时集中查看；处理后迁入正式目录或归档到 archive/buffer。
